The Micronaut Control Panel module provides a web UI that allows you to view and manage the state of your Micronaut
application, typically in a development environment.

The bundled interface follows the https://ui.shadcn.com/[shadcn/ui] dashboard and component design language. It uses
server-rendered Micronaut Views templates with local CSS and JavaScript assets, while matching shadcn/ui conventions for
cards, buttons, badges, dialogs, data tables, tabs, breadcrumbs, sidebars, and light or dark color themes.
